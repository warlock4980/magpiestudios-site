# Red Light Therapy Tracker

Standalone static landing page and tracker for Magpie Studios LLC.

## Files

- `index.html`: landing page and app shell
- `styles.css`: responsive styling and red-light device visual
- `app.js`: localStorage tracker, timer, metrics, chart, CSV export

## Affiliate Link

Replace the temporary direct NovaaLab URL in `index.html`:

```html
https://novaalab.com/
```

with the final affiliate tracking URL from NovaaLab or ShareASale.

## Local Preview

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8080
```

from this directory and visit `http://localhost:8080`.

## Compliance Notes

The page includes an affiliate disclosure near the NovaaLab link and avoids medical cure/treatment claims. Keep any future copy in the same lane: tracking, journaling, personal response, and consistency.
