Quick start

  1. Back up your Mac first. MacJanitor deletes files. A current Time Machine backup is recommended before any cleanup. This is the single most important step.
  2. Open the .dmg and drag MacJanitor to your Applications folder.
  3. Launch MacJanitor. On first run you'll be asked for your Anthropic API key (stored only in your Mac's Keychain — never anywhere else). Free credits available at console.anthropic.com.
  4. Set your user profile in Settings — developer, designer, photographer, casual — so the AI knows what's load-bearing for your Mac.
  5. Scan, review, clean. Every proposed deletion is shown to you before it runs. Conservative by default.
